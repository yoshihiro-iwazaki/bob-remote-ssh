IBM Bob Remote-SSH 接続ガイド

IBM Bob の Remote-SSH で、VSI などリモートの Linux サーバー上のプロジェクトを開発するための手順と、 手元で試せる Docker の検証環境をまとめています。

✅
SSH で入れる Linux なら、Bob から接続できます。
Bob サーバーは初回接続時に Bob が自動でインストールするので、リモート側で Bob 用のインストールや設定は不要です。
README を読む リポジトリを開く

接続先は実業務では VSI などの仮想サーバー、検証では手元の Docker コンテナ。Bob から見るとどちらも「SSH で入れる Linux」です。

使い方

目的に合わせてどちらかを選びます。Bob 側の追加インストールは不要です (Remote-SSH 拡張は Bob に同梱)。

  3. Bob からの接続手順で接続する (Host 設定は VSI 用のものにする)

リモート側の要件

SSH でログインできることに加えて、Bob サーバーの自動インストールに次が必要です。

🔀 SSH のポートフォワード許可
AllowTcpForwarding yes。禁止されていると SSH はつながっても Bob は接続できない
🧩 Linux x86_64 (または ppc64le)
arm64・s390x・Alpine 向けの Bob サーバーは配布されていない
📚 glibc 2.28 以上
目安: RHEL 8 以降、Ubuntu 20.04 以降、Debian 10 以降
🌐 外部への HTTPS
api.us-east.bob.ibm.com に出られること。プロキシは Bob の remote.SSH.httpsProxy で指定
🧰 bash・curl (または wget)・tar
一般的なクラウドの Linux イメージには入っている
💾 ホームに約 450 MB の空き
~/.bobide-server に Bob サーバーを置く

条件を確認するコマンドと詳しい説明は README の「リモート側の要件」を参照。 配布状況と glibc の条件は Bob 1.126.0+bob2.2.3 で確認したもので、Bob のバージョンによって変わることがあります。
